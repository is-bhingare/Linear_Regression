# Linear_Regression
This project involves building a simple linear regression model to predict a target variable based on a single predictor variable. This project focuses on understanding the basic principles of linear regression and model evaluation.

## Run the project

```bash
python /home/runner/work/Linear_Regression/Linear_Regression/linear_regression.py
```

The script performs:
1. Data preparation (load + split)
2. Model building (Scikit-learn `LinearRegression` in a pipeline)
3. Model training
4. Model evaluation (`MAE`, `MSE`, `R2`)
5. Visualization (saves `regression_plot.png`)
